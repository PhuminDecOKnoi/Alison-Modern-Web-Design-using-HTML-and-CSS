Coding Standards

มาตรฐานที่ใช้ใน Repository นี้

HTML Standard

  • ใช้ HTML5 document structure ครบถ้วน
  • ใช้ semantic tags ตามหน้าที่ของเนื้อหา
  • ใส่ `alt` ในรูปภาพ และ `label` ใน form

CSS Standard

  • แยกไฟล์ CSS ออกจาก HTML
  • ใช้ CSS variables สำหรับสีและ spacing
  • ใช้ Grid/Flexbox แทน float สำหรับ layout หลัก

Mini Project

งานมอบหมายปลายบท

สร้าง One-page Website ด้วย HTML และ CSS

ผู้เรียนต้องสร้างเว็บไซต์หนึ่งหน้า โดยมี header, hero section, content cards, form, footer และ responsive layout พร้อมคอมเมนต์ภาษาไทยในส่วนสำคัญของโค้ด
