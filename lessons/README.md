# Lessons 1–8: HTML & CSS Foundation Pack

> ชุดบทเรียน 1–8 สำหรับหลักสูตร **Modern Web Design using HTML and CSS**  
> ออกแบบให้ใช้เป็นสื่อการสอนบน GitHub ได้ทันที: lecture notes + code comments ภาษาไทย + workshop + checklist

---

## Teaching Position: 2026

การสอน HTML/CSS ในปี 2026 ควรวางกรอบดังนี้

1. **HTML** สอนตามแนวคิด **HTML Living Standard** ไม่ยึดติดว่าต้องมี HTML6
2. **CSS** สอนเป็นระบบ **CSS modules** ไม่สอนว่า CSS4 เป็นเวอร์ชันเดียวของทั้งภาษา
3. ผู้เรียนต้องตรวจ **browser compatibility / Baseline / MDN compatibility** ก่อนใช้ feature ใหม่
4. บทเรียนควรเน้น **semantic structure ก่อน visual styling**
5. การบ้านควรส่งในรูปแบบ **GitHub repository** เพื่อฝึก workflow จริง
