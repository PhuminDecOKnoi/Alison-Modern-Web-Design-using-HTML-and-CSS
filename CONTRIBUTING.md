# Contributing Guide

Thank you for improving this HTML and CSS learning repository.

## Contribution Principles

Contributions should be accurate, beginner-friendly, accessible, standards-based, and suitable for classroom or self-study use.

## Content Standards

- Use semantic HTML before adding unnecessary `div` elements.
- Keep CSS readable, organized, and separated from content when practical.
- Use lowercase kebab-case for new file names.
- Explain the purpose of important code with concise Thai comments where it improves learning.
- Preserve responsive behavior across common viewport sizes.
- Provide meaningful `alt` text, form labels, heading hierarchy, and keyboard-accessible interaction.
- Avoid copying copyrighted tutorials, books, or long passages from external sources.
- Use synthetic content and images that may be redistributed legally.
- Link to authoritative references when a lesson depends on a standard or browser behavior.

## Recommended Checks

Before submitting a change:

1. Open the page in a modern browser.
2. Check mobile and desktop layouts.
3. Validate HTML structure where practical.
4. Review keyboard navigation and visible focus.
5. Check color contrast and text readability.
6. Confirm that links, images, and relative paths work.
7. Verify that no secret or personal data is included.
8. Update the README or lesson index when adding a new lesson.

## Commit Messages

Use focused messages such as:

```text
docs: clarify semantic HTML lesson
feat: add accessible contact form example
fix: repair responsive grid layout
refactor: organize shared CSS variables
```
